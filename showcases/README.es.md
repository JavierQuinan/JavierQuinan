## Estándar de evidencia

El portfolio sigue el [Estándar de Evidencia para Proyectos Flagship](../docs/FLAGSHIP_ENGINEERING_STANDARD.es.md). Los roadmaps se mantienen separados de los claims de implementación, el source privado sigue privado y los screenshots públicos deben usar datos sanitizados o sintéticos.
