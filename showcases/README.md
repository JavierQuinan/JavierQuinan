## Evidence standard

The portfolio follows the [Flagship Engineering Evidence Standard](../docs/FLAGSHIP_ENGINEERING_STANDARD.md). Roadmaps are separated from implementation claims, private source remains private, and public screenshots must use sanitized or synthetic data.
