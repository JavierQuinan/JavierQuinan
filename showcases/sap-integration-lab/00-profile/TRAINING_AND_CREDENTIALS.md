## Public certificate evidence

The credentials intentionally selected for this portfolio are backed by their public certificate files. The repository keeps **one canonical evidence file per credential**: original PDF when available, otherwise the original image. Duplicate copies of the same certificate are removed. Certificate evidence preserves issuer branding, holder name, title, date, duration and public verification data; only genuinely sensitive non-verification material is redacted.

The exact certificate links are maintained in the general [Credentials Index](../../../docs/CREDENTIALS.md), which acts as the single source of truth for credential assets across SAP, Odoo and other technical training.

## Topics evidenced by the supplied training material

### ABAP Core / Cloud foundations

The supplied course material covers ABAP development environments, ADT/Eclipse, SAP Business Technology Platform context, ABAP Cloud projects, transport concepts, ABAP language fundamentals, data types, control structures, string processing, internal tables, field symbols, performance considerations and debugging.

### ABAP Cloud — Data Dictionary

The supplied course material covers Dictionary data types, database tables, persistence adjustments, lock objects, Dynamic Cache and database-table relationships.

### abapGit · ATC · ABAP Cleaner · Authorizations

The supplied course material covers abapGit/GitHub repository workflow, ATC / ABAP Test Cockpit, ATC Cloud concepts, ABAP Cleaner profiles/rules, and ABAP authorization concepts including `AUTHORITY-CHECK`, authorization objects and fields.

## How training is used in this portfolio

Training is supporting professional evidence, while engineering capability claims continue to point to source code, tests, sanitized operational guides or executable artifacts. Certificate files prove course/credential completion; they do not upgrade a training credential into a stronger vendor certification category.
