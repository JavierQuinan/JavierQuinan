# SAP Capability Profile

[Versión en español](./README.es.md)

This profile keeps recruiter-facing claims separated into evidence classes instead of treating every guide or course as hands-on experience.

## Positioning

**Enterprise / functional:** SAP ECC MM · SAP IS-U / Work Management · CRM/SD  
**Technical / diagnostics:** ABAP Objects · SALV · debugging · status/data analysis  
**Historical hands-on ABAP:** ABAP Core · ABAP Objects · ABAP Cloud classrun · internal tables · field symbols · Open SQL · exception handling  
**Modern SAP architecture/study:** Clean Core · RAP architecture · Migration Cockpit  
**Client-side engineering example:** S/4HANA procurement/OData client with tests, explicitly non-live

## Evidence classes

1. `ENTERPRISE_VERIFIED` — sanitized operational knowledge from real SAP work.
2. `HANDS_ON_HISTORICAL` — personal labs with historical execution evidence; current runtime may still be pending.
3. `PUBLIC_SOURCE_EVIDENCE` — reviewable source in this repository.
4. `EXECUTABLE_NON_LIVE_EXAMPLE` — executable/tested example without a live SAP connectivity claim.
5. `DOCUMENTATION_GROUNDED` — architecture/study grounded in documentation.
6. `TRAINING_ONLY` — completed training without independent runtime evidence.
7. `NOT_YET_EVIDENCED` — no current portfolio basis for a hands-on claim.

## Claim boundary

Training is not presented as SAP-issued certification or runtime evidence. RAP architecture and integration concepts are documentation-grounded. The procurement client is an executable non-live example. The historical ABAP labs have historical execution evidence but remain pending current re-execution.
