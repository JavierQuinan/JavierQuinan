# SAP Capability Profile

[Versión en español](./README.es.md)

This section separates three different kinds of evidence so the SAP profile stays recruiter-readable and technically honest:

1. **Enterprise experience evidence** — sanitized operational knowledge and troubleshooting guides derived from real SAP work.
2. **Engineering evidence** — reviewable source code, deterministic tests, integration clients and reproducible build guides published in this repository.
3. **Training & credentials** — completed external training documented as training, without presenting third-party course completion as an SAP official certification.

## Positioning

**Functional / process:** SAP ECC MM · SAP IS-U / Work Management · CRM/SD  
**Development / diagnostics:** ABAP Objects · SALV · ABAP Unit patterns · debugging · ATC-oriented quality · abapGit  
**Modern SAP:** ABAP Cloud · Clean Core · RAP architecture · S/4HANA procurement APIs  
**Integration:** OData · REST · SOAP · observability · correlation IDs · error mapping

## Evidence rule

A capability is only marked as public engineering evidence when a corresponding artifact exists in this repository. Training is listed separately and does not by itself imply production implementation, live S/4HANA tenant access, or SAP-issued certification.
