> General, recruiter-facing credentials index. Each entry uses the exact term its own issuing document states — no credential is upgraded to a stronger certification label than the issuing document itself supports. Public certificate evidence is linked directly when available.

## Evidence policy

Certificates intentionally selected for this portfolio are public evidence. Prefer **one canonical evidence file per credential**: the original PDF when available, otherwise the original image. Do not publish duplicate copies of the same certificate in multiple formats unless a preview is technically necessary. Issuer branding, certificate title, holder name, date, duration and public verification data should remain intact. Redact only genuinely sensitive material that is not part of public credential verification, such as private account URLs, private email addresses, national identifiers or secret/token material.
